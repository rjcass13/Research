\section{Context}

    \begin{frame}
        \frametitle{What are we doing?}
        \begin{itemize}
            \item Want to understand the dependence between climate variables (temperature, precipitation) and geography/time
            \item Want to create a model to capture the relationship between Latitude, Elevation, and Time, on Temperature and Precipitation
        \end{itemize} 
    \end{frame}

    \begin{frame}
        \frametitle{Why are we doing this?}
        \begin{itemize}
            \item Want to understand the evolution of the parameters of the model in the modern climate
            \item Want to establish a baseline relationship of geography/time on climate variables to apply to ancient data
            \item  
                \begin{itemize}
                    \item Paleogene era: 66-23 Mya
                    \item Proxy data (fossils, deposition layers, etc.)
                    \item Data Sparsity
                    \item Makes modeling covariate-dnver? mean structure extremely important
                    \item $Y(s, t) = x(s, t)\beta + \epsilon(s, t), \epsilon \sim N(0, \sigma^2 I)$
                    \item Can learn appropriate structure for $x\beta$ from modern data (best design matrix)
                \end{itemize} 
            \item Put me through my paces
        \end{itemize} 
    \end{frame}
